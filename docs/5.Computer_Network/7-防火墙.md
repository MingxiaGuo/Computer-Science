Linux 系统中有多种防火墙解决方案，最常用的是 `iptables`、`nftables` 和 `firewalld`

## 1. iptables (传统防火墙)

iptables 是 Linux 最经典的防火墙工具，通过 Netfilter 框架实现。
最基础的 Linux 防火墙
特点：功能强大，配置灵活但较复杂

基本概念：
- **表(Tables)**：filter(默认)、nat、mangle、raw
- **链(Chains)**：INPUT、OUTPUT、FORWARD(在filter表中)
- **规则(Rules)**：匹配条件和动作

常用命令：
```bash
# 检查 iptables：
sudo iptables -L

# 查看当前规则
sudo iptables -L -n -v
sudo iptables -L -nvx
sudo iptables -L -v # 显示详细信息，包括包计数器和字节计数器
sudo iptables -L -n # 显示端口号而不是服务名
sudo iptables -L --line-numbers # 显示规则的行号

# 允许已建立的连接
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许SSH连接(22端口)
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许HTTP(80端口)
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# 默认拒绝所有其他入站连接
sudo iptables -P INPUT DROP

# 保存规则(取决于发行版)
sudo iptables-save > /etc/iptables.rules
```

## 2. nftables (iptables的替代品)

nftables 是 iptables 的现代替代品，提供更简洁的语法和更好的性能。
新一代的包过滤框架
特点：替代 iptables，性能更好

### 基本使用
```bash
# 查看当前规则集
sudo nft list ruleset

# 添加简单防火墙规则
sudo nft add table inet filter
sudo nft add chain inet filter input { type filter hook input priority 0 \; }
sudo nft add rule inet filter input tcp dport 22 accept
sudo nft add rule inet filter input tcp dport 80 accept
sudo nft add rule inet filter input ct state established,related accept
sudo nft add rule inet filter input drop
```

## 3. firewalld (动态防火墙管理器)

firewalld 是许多现代Linux发行版(如RHEL/CentOS/Fedora)默认的防火墙解决方案。
CentOS/RHEL 7+ 默认的防火墙
特点：动态管理，支持区域管理
常用命令：
```bash
# 检查 firewalld (CentOS/RHEL 默认防火墙)：
sudo systemctl status firewalld

# 查看防火墙状态
sudo firewall-cmd --state

# 查看活动区域和规则
sudo firewall-cmd --list-all

# 永久开放HTTP服务
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload

# 开放特定端口
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload

# 限制特定IP访问SSH
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.100" service name="ssh" accept'
sudo firewall-cmd --reload


```

## 4. UFW (Ubuntu简单防火墙)

UFW (Uncomplicated Firewall) 是Ubuntu的简化防火墙工具。Ubuntu 默认的防火墙。
特点：配置简单，适合新手使用
基本使用：
```bash
# 检查 UFW (Ubuntu 默认防火墙)：
sudo ufw status

# 启用UFW
sudo ufw enable

# 允许SSH
sudo ufw allow ssh

# 允许特定端口
sudo ufw allow 80/tcp

# 拒绝特定IP
sudo ufw deny from 192.168.1.100

# 查看状态
sudo ufw status verbose
```

## 防火墙管理建议

1. **默认策略**：始终设置默认拒绝策略
   ```bash
   sudo iptables -P INPUT DROP
   sudo iptables -P FORWARD DROP
   sudo iptables -P OUTPUT ACCEPT
   ```

2. **保存规则**：确保重启后规则仍然有效
   - iptables: `iptables-persistent` 包或 `iptables-save`
   - nftables: `nft list ruleset > /etc/nftables.conf`
   - firewalld: 规则自动保存

3. **日志记录**：记录被拒绝的连接
   ```bash
   sudo iptables -A INPUT -j LOG --log-prefix "IPTABLES-DROPPED: "
   ```

4. **定期审查**：检查防火墙日志
   ```bash
   sudo grep IPTABLES-DROPPED /var/log/syslog
   ```

## 选择建议

- **服务器**：使用 firewalld (RHEL系) 或 UFW (Debian系)
- **高级用户**：直接使用 nftables 或 iptables
- **容器环境**：考虑结合网络命名空间和防火墙规则

记住，防火墙只是安全的一个层面，应该与其他安全措施(如SELinux/AppArmor、系统更新等)结合使用。
